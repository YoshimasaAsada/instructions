# Fix Spec from Review

レビューレポートの指摘をもとに、仕様書を修正する。

- **目的:** `review-spec.md` の指摘を仕様書に反映し、再レビューで承認されるレベルに引き上げる
- **入力:** `{name}.spec.md` + `{name}.review.md`
- **出力:** 更新された `{name}.spec.md`（上書き）

---

## 実行フロー

### Phase 1: 指摘の読み込みと分類

`{name}.review.md` の全指摘を読み込み、優先度別に整理する。

- 🔴 高・🟡 中: 必ず修正する
- 🟢 低: 修正内容が明確なものは修正、判断が必要なものはスキップして注記する

---

### Phase 2: 仕様書の修正

`{name}.spec.md` を読み込み、各指摘に対応する箇所を修正する。

修正ルール:

- 仕様書の**固定フォーマット**（セクション構成）は変えない
- 指摘に対応できない場合は `## 前提・解釈` セクションに理由を追記する
- セクションの追記・削除はしない（内容の書き換えのみ）

---

### Phase 3: 出力サマリー

修正完了後に以下を出力する:

```
## 修正サマリー

- 対応した指摘: N件（🔴 N件 / 🟡 N件 / 🟢 N件）
- スキップした指摘: N件（理由: ...）
- 更新したセクション: {セクション名}, {セクション名}

次のステップ: review-spec.md で再レビューを実行してください。
```
