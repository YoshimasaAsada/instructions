# 画面の見た目の確かめ方

デザイン（Figma 等）がある画面を実装・修正したときに、ブラウザで確かめる手順。数値をデザインに合わせただけでは、並べたときのずれ・デザインに無い幅での崩れ・片方の状態でしか見ていないことに気づけない。

1. **デザインと同じ幅で並べる。** デザインにある幅（SP・PC）ごとに同じ幅でスクショを撮り、デザインのスクショと並べる。位置・大きさ・省略の行数・揃え（左・中央）・画像の大きさを1つずつ突き合わせる。SP と PC で値が違う指定（揃え・行数・列数）は、両方のノードから取る。
2. **デザインに無い幅も見る。** プロジェクトのブレークポイントの境界の前後で撮り、間延び・はみ出し・崩れを見る。多段グリッドの列数を増やす幅は、ここで崩れないことを確かめてから決める。
3. **表示が分岐する状態をすべて見る。** 0件・取得失敗・任意項目の有無（タグあり/なし等）・非表示中のブロックは、データを用意するか一時的に表示させて確かめる。片方の状態で測った結果を、もう片方にも当てはまるように報告しない。
4. **ページ全体を見る。** SP 幅でページ全体をスクロールし、固定表示の要素（追従バナー・ヘッダー）と重ならないかを見る。
5. **書き出した画像は表示して見る。** 透過・切り抜きの範囲（ページの背景が入っていないか）を確かめる。

過去事例: ページのリニューアルで、人物の画像がデザインより 14% 小さい、768〜991px で FV が間延びし2列・3列のカードが崩れる、SP だけ左寄せの注記を中央寄せにしていた、タグの無いデータで「カードの高さが揃った」と報告した、背景込みでアイコンを書き出した、のいずれもレビューやユーザーの指摘で見つかった。
