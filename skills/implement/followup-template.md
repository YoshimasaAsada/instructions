# followup.md テンプレート

```markdown
# 実装メモ: <機能名 / 依頼の要約>

## 既存実装への改善提案

### <提案の要約>

- 対象: `path/to/file.rb:120`
- 現状: <今どうなっているか>
- 提案: <どうするとよいか>
- 根拠: <なぜそう言えるか。プロジェクト規約・既存の類似実装・一般的な原則のどれに基づくか>
- 影響範囲: <巻き込むファイル・機能。テストの有無>
- 今回見送った理由: <スコープ外 / 影響範囲が大きい 等>

## 横展開したいプロジェクト規約の候補

### <規約案の要約>

- 内容: <守るべきこと>
- 根拠: <今回どこで問題になったか。踏んだ失敗があれば具体的に>
- 想定する追加先: `.claude/rules/<project>/<file>.md` / `<project>/CLAUDE.md`
- 文面案: <そのまま貼れる形の本文>

## 用語集への追加候補

- **<用語>**: <定義1〜2文。プロジェクトに CONTEXT.md / 用語集がある場合はそこへの追加候補として。実装中に「この概念に名前がなくて説明が冗長になった」ものを拾う>

## 要確認（採否を判定できなかった指摘）

- <指摘内容>: <推奨案>
```

該当がないセクションは節ごと省略する。
